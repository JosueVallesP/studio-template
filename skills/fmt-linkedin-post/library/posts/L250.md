## Post

My sales deck converted over 73% in Q2. So I turned it into a live website (breakdown below). 

"Your LinkedIn profile is your landing page". 

That was a nice jingle in '24 when reach was decent. 

Today, getting people in calls, in the DMs, or on email lists is much harder. 

You need a page that you actually own and can personalize for conversion (aka a real website). 

I haven't had a website since 2018 so I tried Claude Code.

The first concept was okay-ish but the prompting took ages. 

And I'm a visual guy: 

I like widgets. I like drag-and-dropping stuff. I want to see features before I add them. 

So I used Wix Harmony to build and personalize my website: 

1. Picked the sales deck converting at 73%
2. Fed it to my LLM to reverse-engineer website prompt
3. Dropped the prompt into Wix Harmony
4. Added a fully functional booking form
5. Published a site with a built-in domain and SEO
