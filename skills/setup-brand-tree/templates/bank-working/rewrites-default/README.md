# Default pairs

Ten rewrite pairs from the studio's author: the studio's draft beside the version the author rewrote, each change tagged with the rule it touches (a house rule, H or S, from `skills/craft-house-rules`; a default voice rule, W1 to W10, from the default voice guide; or `piece` when the change belongs to that one piece). They ship with the studio so a new person's writer isn't learning from nothing on day one.

**Read them for what was cut and why, never for the words.** The left side shows the moves a model makes when it composes from a summary (decorative images, a generic "someone", a landing line, a verdict with no why). The right side shows one person's fix. The right-hand sides were neutralised: the phrases personal to the author were replaced with plain wording in the same register. The habits are worth learning; a draft that copies a pair's wording fails the swap test.

`scripts/rewrites.py pick` lists these only while `bank/rewrites/` holds fewer than three of the person's own pairs, labels them `default`, and hands only the pairs whose `format:` matches the piece (a studio-message pair never goes to a post or an essay). After that it stops.

The tenth pair (J) is the one with no rewrite: written from the author's own paragraph with the three-draft method, and read as human by the detector. It's there to show what the method produces when it starts from the person's words.
