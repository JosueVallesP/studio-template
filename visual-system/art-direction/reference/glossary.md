# Glossary

One meaning for every term the four skills share. Where a skill's own terms
section says something different, this file wins until that skill is corrected.
A term only one skill uses stays in that skill.

Terms about the canvas, type, colour and layout (canvas, frame, downscale factor,
type floor, measure, rank, token and the rest) are defined in the design plugin's
`reference/glossary.md`, and its `reference/canvas-assumptions.md` holds every
shared number. This file does not repeat them.

## The roles

**Art direction.** Deciding what a piece has to be, writing that down so a maker
can be held to it, and judging whether what came back is it.

**Design.** Making the piece: the grid, the type, the palette, the placement. The
design plugin owns it.

**Maker.** Whoever makes the piece: a photographer, an illustrator, a designer, an
image model or an agent. The maker cannot read your mind. Do not use "executor".

## What gets written

**The ask.** One sentence saying what the work has to do: its subject, the feeling
it should give and the one quality it must have. It is written before any image
is gathered or any visual choice is made. It applies to a board, a set of rules
or a single image alike.

**The feedback request.** What a maker wants from a critique on one occasion: the
kind of feedback and how structural it may be. It is separate from the ask and
from the brief.

**Brief.** The document that says what a piece was commissioned to do. Whoever
commissions the piece supplies it.

**Specification.** Any written instruction whose every line a second reader can
check against the finished piece, with no access to the author. A brief becomes a
specification when every line passes that test. On a reference board, one
specification line has four parts: the reference, the attribute taken, where it
lands in the piece, and how much.

**Direction.** The written rules a body of work is held to, each one written so a
finished piece can break it. A direction outlives any single piece.

**Style.** The look a finished piece has. A style can be described and
recognised. It cannot be failed, so it is not a direction.

**Prohibition.** A line of a direction that says what must not appear or happen,
written so a finished piece either breaks it or does not. Do not use
"proscription".

**Gate.** A named moment when the direction or the brief is applied to a piece,
with a stated consequence for failing.

## Boards

**Moodboard.** A set of images that share a feeling, with no note on what each is
there for. It cannot be judged against.

**Reference board.** A reduced set of images where every image carries a note
naming the one attribute taken from it. `ad-board` owns sourcing, reducing and
annotating one. The other three skills take it as an input.

**Anti-reference.** An image of the thing being avoided, placed on a reference
board and labelled as forbidden.

## Phases

**Exploration.** The phase where the direction is not settled and structural
options are open.

**Refinement.** The phase after a direction is agreed, where only execution
changes.

## Image handling

**Treatment.** One written set of operations applied the same way to every image
in a set: the grade, the grain, the retouching level, the crop convention. A
treatment applied to some images and not others is not a treatment.

**Grade.** A deliberate shift of an image's colour and tonal values after it
exists.

**Crop.** Choosing a rectangle inside an image and discarding the rest.

**Aspect ratio.** The width-to-height proportion of the delivered file. It is a
field of the brief, not a crop.

## Marks used in the skills

**(thin).** The rule or number rests on a single source, or was inherited without
a reason. Treat it as a default you may change, and say so when a finding rests
on it.
