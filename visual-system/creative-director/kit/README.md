# The kit

The kit is the script and the notes a brand's package gets built from. It is not in this version of the studio.

The first kit was written while building one person's visual system, and it still carried that person's mark and art as its samples. A person's look belongs to that person, so the kit was taken out before it could ship. It comes back when its samples are neutral ones.

Until then, `cd-system` runs as far as the approved values (`system/tokens.json`) and stops before "Build the package". `/visual` makes pictures the way it did before: from the Figma kit, or as a neutral SVG styled from the person's values.
