# Substack inline diagram

**For:** a diagram placed inside an essay at the moment the reader needs it. The reader has already chosen to read, so it can carry more detail than a feed image. It should still make sense if someone screenshots it and shares it alone.

**Size:** match the post column width. Confirm Substack's current column and image widths and record them here with the date.

## Parts

1. **A short title** that states what the diagram shows.
2. **The diagram,** shaped by the idea (see `taste/rules/diagram-form.md`).
3. **Labels** in the essay's own words, so the reader connects the two.
4. **Name or mark,** small, for when it's shared alone.

## Read speed

The reader gives it several seconds, since they're already in the essay. The shape should still land at a glance.

## What generic looks like here

A diagram that repeats the paragraph above it instead of showing something the words can't; a template shape chosen because the essay "needed a visual."
