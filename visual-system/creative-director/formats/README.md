# Formats

One spec per recurring format, per platform. `cd-make` reads the one named in the visual brief; the legibility reviewer checks against it.

Each spec has the same parts: what the format is for, size, the parts it's made of, how fast it must be read, what generic looks like in this format, and open questions. Sizes marked "confirm" should be checked against the platform's current guidance before relying on them, and the check dated in the file.

Add a format when a piece type comes up a second time.
