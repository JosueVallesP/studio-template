# LinkedIn carousel

**For:** an idea that needs a sequence: steps, a before and after, a set of parts, a short field guide. Posted as a PDF document, one page per slide.

**Size:** 1080 × 1350 pixels per page (4:5 portrait). Confirm against LinkedIn's current guidance.

## Parts

1. **First page:** the idea stated plainly, and enough of the visual language that the reader knows what they'll get. It must work as a stand-alone image, since it's the only page most people see.
2. **Middle pages:** one point per page, each with the same layout grid so the eye knows where to look.
3. **Last page:** the whole idea in one view, so a reader who skipped to the end still gets it. The name or mark.

## Read speed

Each page in a few seconds. The first page in two.

## What generic looks like here

A hook in giant type with one highlighted word; numbered pages that are only a list split up; a different layout on every page.
