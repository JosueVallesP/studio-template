# Diagram form

**The rule: the shape comes from what the idea does.** Pick the form after you know the relationship the idea rests on, never before. A framework drawn in a familiar shape because the shape is familiar is generic, even when it's on brand.

## Find what the idea does

State the idea in one or two plain sentences. Then find the logic under it. Ideas with a shape usually contain one of these:

| What the idea does | Forms that fit | What the reader understands without being told |
| --- | --- | --- |
| One thing matters more | Scale: shapes of different sizes | Bigger is more |
| Things sit between two extremes | A spectrum line | Position shows where it falls |
| Things happen in order | A timeline, left to right | Left came first |
| One thing produces another | An arrow or chain | This causes or becomes that |
| Two forces trade off | Two axes, a balance | Gaining one costs the other |
| Things share ground | Overlapping shapes | The overlap combines both |
| A choice changes the outcome | A branch | A decision sends you down a path |
| Some things hold up others | Layers, a pyramid, a tree | What's below supports what's above |
| One thing changes as another changes | A curve on two axes | The line's shape is the behavior |
| Something feeds itself | A loop | It keeps happening |
| Two states of the same thing | Side by side, same marks, one change | The difference is the point |

For charts of real numbers, use the Financial Times Visual Vocabulary groups: deviation, correlation, ranking, distribution, change over time, magnitude, part to whole, spatial and flow.

If the idea has none of these, say so. It may work better as words, or it may need sharpening before anyone draws it. Send it back to whoever wrote the visual brief.

## Prefer these mechanics, in this order

1. One repeated mark that changes in one way (size, count, position, darkness).
2. The same marks in two states, changing only what the idea is about.
3. Scale, when the idea is about size.
4. A borrowed symbol the reader already knows, twisted if it's worn out.
5. A metaphor built from a property the idea really has.
6. Labeled boxes and arrows, only when the idea really is a step-by-step procedure.

## Don't claim more certainty than exists

Clean lines read as settled fact. If the categories blur in real life, let the drawing show that. Don't draw exact proportions or counts that nobody measured.
