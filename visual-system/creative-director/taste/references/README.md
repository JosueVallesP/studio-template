# Reference library

Brands and people worth pointing a client to, with what each one signals and who it would fit. `cd-intake` uses it when a client's own references are thin, and `cd-direction` uses it to explain a direction with real examples.

How to use an entry: to name what a look signals and why. Never to copy the look. A brand can't be distinctive by borrowing someone else's distinctiveness.

How to add an entry: one row in `library.md`. Write what it signals from what you can see, not from what the brand says about itself. Add who it would fit and who it would mislead.
