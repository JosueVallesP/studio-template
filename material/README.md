# Material

Everything you've already made, in your own words. This folder is yours; a studio update never touches it.

Put here, as plain text or Markdown files (one file per thing, or one file per batch, it doesn't matter):

- Your best posts, as you published them.
- Essays, newsletters, articles, chapters.
- Transcripts of you talking: talks, podcasts, calls, voice memos.
- Stories you tell, with the details as you remember them.
- Opinions you've written down, even as rough notes.
- Numbers and results you can state.

The studio reads this folder directly. The job commands (`/post`, `/essay`, `/strategy`, `/visual`, `/identity`) work from it on day one, with no interviews. The interviews and the canon add to it; they don't replace it.

The difference from `inbox/`: `inbox/` is for what just happened (a call yesterday, a thought this morning), and `/capture` sorts it and moves it to `inbox/done/`. `material/` is what you've made and keep: it stays here and gets read every time.

Only your own words go here, because the studio reads this folder as your voice. Other people's posts you want to learn from go to `/teardown`, which keeps the breakdown in `bank/swipe-file.md` and the whole post in `bank/swipe/`, for you to read whenever you want inspiration.

Audio and video need a transcript first; the studio can't read them.
