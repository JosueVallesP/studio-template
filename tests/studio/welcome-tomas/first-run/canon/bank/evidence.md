# Evidence ledger

One line per mention of something the canon doesn't hold, holds in other words, or has been asked for. Capture and the editor write lines; the librarian counts them and writes a proposal to `proposals.md` when the count is there (a belief stated three times, a story reached for twice, a voice edit made twice). This file is not a to-do list for the person; `proposals.md` is.

Format: `<date> · <kind> · <canon ID or new> · <I ID or piece ID> · "<the line>"`
Kinds: new POV · new story · new proof · new method (a behavior, layer A) · definition · repeat · contradiction · limit confirmed · voice edit · asked for · note (for the strategist)
A line that earned a proposal gets `→ proposal <date>` appended; one held back by the five-proposal cap gets `· earned <date>`.
